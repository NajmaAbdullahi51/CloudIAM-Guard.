
# CloudIAM Guard

A Python-based AWS IAM security
policy auditing mini project.

## Features
- Scans IAM JSON policies
- Detects wildcard permissions
- Identifies wildcard resources
- Detects wildcard principals
- Generates security warnings

## Technologies
- Python
- JSON
- AWS IAM concepts

## How to Run

python main.py policy.json

## Expected Result

WARNING: Security risks found!

[!] Statement 1: Wildcard Action
[!] Statement 1: Wildcard Resource

## Purpose

This project demonstrates basic cloud
identity and access security auditing.

## Disclaimer

Educational security auditing tool.
Not a complete AWS security scanner.
